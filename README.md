# Мокрый нос

Демонстрационный сайт студии груминга в Москве, адаптация визуального референса [Tubwell](https://tubwell.visuvate.com/) для портфолио. Вымышленные адрес, команда и цены. Настоящие заявки не отправляются.

## Запуск

```sh
npm ci
npm run dev
```

Адрес: http://127.0.0.1:5173/. Для статического размещения: `npm run build`, результат в `dist/`. `npm test` проверяет все 20 маршрутов, наличие локальных ресурсов и локальный демонстрационный обработчик.

## Публикация на GitHub

Репозиторий: https://github.com/Vladnes7/mokry-nos. Сайт: https://vladnes7.github.io/mokry-nos/.

GitHub Pages получает готовую статическую сборку из ветки `gh-pages`. Команда `npm run build:pages` готовит пути для `/mokry-nos/`; `npm run check:pages` проверяет ссылки и ресурсы. Для другого имени репозитория задайте `PAGES_BASE=/имя-репозитория/` обеим командам. Обычная локальная сборка и запуск работают от корня `/`.

В репозитории включены все оптимизированные фотографии, нужные для работы сайта. Тяжёлые исходные PNG генераций хранятся локально и исключены из Git; для обычного запуска и сборки они не нужны.

## Готовая версия

Адаптированы все 20 страниц: главная, услуги и самомойка, студия, магазин, 13 карточек товаров, запись и две информационные страницы. Русские тексты включают формы, ошибки, календарь, корзину, подсказки, подписи схем и описания изображений. Цены — в рублях, вес — в килограммах, размеры товаров — в метрических единицах.

Все фотографии заменены: 49 сгенерированных изображений для питомцев, услуг, студии, команды, галереи и товаров. Для внутренних разделов подготовлены 183 варианта размеров из 44 новых изображений. Исходные фотографии референса не используются в отображаемых блоках. Итоги проверки — в [отчёте приёмки](docs/reference/acceptance.md).

## Устройство

- `site/` — локальные HTML-страницы; исходники сборки уже включены в проект.
- `src/ru.tsv` — перевод. `src/brand.css` — русская типографика и правки компоновки. `src/demo.js` — локальная демонстрация без передачи контактных данных.
- `public/wp-content/` — сохранённая техническая основа референса: стили, ресурсы и движок взаимодействий. Она используется прямо, чтобы сохранить исходную геометрию и поведение. Проект не является заново написанным движком Tubwell.
- `public/fonts/` — локальные Onest и Caveat с кириллицей; три оригинальные гарнитуры русские глифы не содержат.
- `scripts/import-reference.mjs` — воспроизводимое получение публичного референса в игнорируемый кэш `.reference/`. Для обычного запуска и сборки повторное получение не нужно.
- `scripts/adapt.mjs` — адаптация кэшированных страниц; `npm run adapt` применяется только после импорта.
- `scripts/prepare-images.mjs` — композиционные кропы и WebP-копии фотографий; использует Sharp из установленного рабочего runtime. Готовые изображения включены в проект, обычный запуск не зависит от этого runtime.
- `src/image-plan.json`, `scripts/prepare-all-images.mjs` — план новых фотографий и подготовка всех адаптивных вариантов; `docs/reference/image-replacements.json` содержит карту замен.
- `docs/reference/` — план, карта разбора, результаты проверки.

Выбор статических страниц вместо предложенного ранее React сохраняет геометрию и исходное движение без добавления второго механизма анимаций. Vite нужен для локального сервера; готовый сайт не требует WordPress или сервера PHP.
